# 操作说明

本文针对 [`hdmi_camera.py`](../ch341_driver_work/hdmi_camera.py) 的 GTK 界面。先完成 [构建与部署](BUILD.md)及 [接线核对](WIRING.md)；源码目录与板端部署目录的文件布局不同，不要把单个界面文件复制过去就当作完整安装。

## 启动与状态核对

按部署方式启动界面后，先核对 OV5647 画面是否持续更新、普通遥测是否在线、是否有故障或等待提示。画面在线、识别在线、控制在线是独立状态，任何一个都不能代替其他两个。

人员跟随可通过界面的“跟随模式”按钮准备，也可用部署模式 `--follow person` 启动界面；随后仍需识别到人并明确按 `0`。`--navigate ROUTE_JSON` 和 `--mission MISSION_JSON` 是独立启动模式，不与 `--follow` 同时使用。串口设备、相机和模型位置按 [构建说明](BUILD.md)配置。

`rk/main.py` 使用另一套交互和可选 `--enable-drive` 模式；`browser_viewer.py` 提供只读监视。不要同时运行多个串口读取者或相机采集程序。

## 遥控与停车

| 按键 | GTK 配套行为 |
| --- | --- |
| `5` | FPGA 直接停车；相关条件恢复后清除故障锁定。故障原因仍需按提示处理 |
| `0` | 人员跟随模式下启动跟随；导航专用启动模式中有该模式的启动/重准备含义 |
| `7` | 请求沿配置路线逐点搜索瓶子，先停车准备，再明确执行，无需再按 `0` |
| `9` | 切换 U 盘摄像头录像，与停车命令独立 |
| `2` / `8` | 前进 / 后退 |
| `4` / `6` | 前向左转 / 前向右转 |
| `1` / `3` | 定点左旋 / 定点右旋 |
| `VOL+` / `VOL−` | 调速；跟随默认档 8，步长 2，范围 4～12，手动档独立 |

**方向键点按后持续执行，松手不会自动停止；使用 `5` 停车。** 界面的“停车”按钮也会发出停车请求。`Esc` 或 `q` 退出界面。界面切页和“详情”开关只改变显示。

跟随时有效超声波距离 ≤60 cm 保持停车，不自动扫描绕障。手动/导航前向运动在有效近距 <20 cm 时制动，并可进入扫描绕障流程。当前既有策略不因超声波缺测而阻止运动；IMU、控制链路及反馈故障仍可能停车。不要把“无有效测距”读成“前方没有障碍”。

## 路径寻瓶与任务六方向

`7` 键读取部署目录中的路线配置；仓库默认 [`route_example.json`](../robot_rebuild/rk/route_example.json) 为 `(1000,0) → (1000,1000) → (0,1000) → (0,0)`，单位 mm。代码已实现请求与任务状态机，当前记录仅确认启动命令被接受，实际路线和寻瓶完成过程待验收。

“任务6”使用预设地点和受支持的中文指令模板，不是任意自然语言视觉模型。操作为：点“任务6” → 选择地点任务或输入指令 → “生成任务（不启动）” → 核对任务提示 → 点“执行任务6”。生成新任务会准备以当前车位和车头为原点，同一任务中的地点始终相对该固定基准，不随中途转向改变。

[`mission_semantic_example.json`](../robot_rebuild/rk/mission_semantic_example.json) 的默认地点为：

| 地点 | X / Y（mm） |
| --- | --- |
| 前方 | `1000 / 0` |
| 左边 | `0 / 1000` |
| 右边 | `0 / -1000` |
| 后边 | `-1000 / 0` |
| 左前方 | `1000 / 1000` |
| 右前方 | `1000 / -1000` |

`+X` 为初始前方，`+Y` 为初始左方。斜向是两轴各 1 m，直线距离约 1.41 m。每个地点提供导航、找人、找水瓶三个模板，例如“去前方停车”“去左边找人”“去右前方找水瓶”。地点和指令解析已在板端核对，实际行驶与任务完成仍待验收。

## 全屏雷达地图

收到支持地图的固件发出的 C9 帧后，摄像头页出现“雷达地图”按钮。点开独立地图页，点“返回摄像头”切回。地图页保留“停车”按钮；切换页面不会启动雷达接管。

车头朝上，左右与车体一致。橙点表示各扇区最近的有效障碍距离，灰色为未知区域，包括障碍点之后未测得的区域。由内到外四圈为 1、2、4、8 m，画面采用分段距离映射，应按标尺读数。重复旧扫描、超时或断开后撤下旧障碍标记。

`0000F7C8` 观察地图固件提供这一显示通路；源码默认 `LIDAR_MAP_DISPLAY=0`，普通观察固件不一定发送地图。显示开关和运动接管开关的区别见 [架构](ARCHITECTURE.md)。

## U 盘录像

插入可用 USB 存储，按 `9` 或点“开始录像（9）”。以界面“准备中 / 正在录像 / 保存中 / 已保存 / 错误”提示判断状态；再次按 `9` 停止，等待保存完成后再移除存储。`5` 只停车，不会停止录像。

默认配置为 10 fps、每段 300 s，最小剩余空间 512 MB、单段容量上限 256 MB。录像写入已验证的 USB 存储，不自动回落到内置存储。配置见 [`recording_config.json`](../robot_rebuild/rk/recording_config.json)。

这一路保存摄像头图像和状态叠加，不是整个桌面或雷达地图页的屏幕录像。历史地图窗口录像是独立验证记录。

## 离线查看 C8

在仓库根目录运行，输入文件需要事先存在；输出目录必须是新目录，父目录需已存在：

```sh
python robot_rebuild/tools/export_lidar_planning.py --from-binary capture.bin --output-dir planning-export
```

结果为 `planning.csv` 和 `summary.json`。退出码 `0` 表示该文件离线数据质量检查通过，`1` 表示文件/参数处理失败，`2` 表示无有效帧、坏帧或尾部残留。它们不表示车辆当前在线，也不构成实车验收。
