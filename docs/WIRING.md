# 当前接口

适用型号：ACG138-RK3588 + FPGA，GW5AT-LV60PG484AC1/I0。下表摘自工程约束 `robot_rebuild/fpga/robot.cst` 与原接线记录。实际排针方向以板上 1 脚标记及对应版本原理图为准。

| 信号 | P7 脚 | FPGA 球位 |
|---|---|---|
| IMU TX → FPGA RX | 1 | V15 |
| 左、右超声波 TX | 2、3 | U15、T15 |
| 左编码器 A/B | 4、5 | T14、U16 |
| 右编码器 A/B | 6、7 | N15、P16 |
| 左电机 PWM / IN1 / IN2 | 8 / 9 / 10 | R17 / R18 / T18 |
| 右电机 PWM / IN1 / IN2 | 13 / 14 / 15 | N13 / N14 / P14 |
| 电机驱动 STBY | 16 | R14 |
| 可选常闭急停输入 | 17 | P15 |
| 可选雷达 UART RX | 18 | R16 |
| 5V / GND | 11 / 12 | 电源 / 地 |
| 3.3V / GND | 29 / 30 | 电源 / 地 |

传感器、编码器、驱动板与开发板共地。信号接口按 3.3V 电平接入，不把 5V 信号直接输入 FPGA。STBY 由 FPGA 控制，原固定接 3.3V 的线应移除，外部 10kΩ 下拉使未配置时驱动关闭。红外 E3 使用 VCCADJ，当前约束为 2.5V，对应 P20 的 1–2 档；换跳线时必须核对约束。

当前 `USE_EXT_ESTOP=0`，P7-17 留空，遥控 5 键停车。只有构建为 `USE_EXT_ESTOP=1` 时才按常闭触点接法启用该输入；遥控停车不等同独立硬件断电。

## 摄像头、雷达和调试线

- OV5647：匹配的 24P MIPI 排线接 RK 的 FPC2（CSI0），图像由 RK 采集。FPGA 保留的 DVP 接口与此排线不同，不能混接。
- X3 Pro：原配转接盒 DATA 接 RK 的 USB-A 数据口。POWER 为转接盒供电口，按原配规格供电。RK 转发原始字节，FPGA 解析测距、扇区与地图。
- DEBUG：正常运行时用独立 USB 数据线接回 RK 的 USB-A 口，使 RK 能收到 FPGA 遥测。下载 FPGA 时才临时接电脑。
- HDMI：接 RK 的 HDMI 输出；屏幕和开发板分别满足各自供电要求。

雷达转动只能说明电机在转，不能证明 DATA 通信正常。以界面扫描数增长、有效数据及错误计数核对。

当前地图观察配置不让雷达接管运动，运动仍沿用原控制。轮距 100mm、每米 7640 编码器计数等是工程配置值，不能当作已经完成的实车标定。
